## Who we are

**Conqrex** is an independent software & game development studio. We build our own engine, our own desktop host, our own networking — then we build games on top of them.

## ⚙️ Conqrex.Engine

One C# codebase rendering 2D, 2.5D isometric and 3D — the foundation under every Conqrex title.

- 🌐 **Every surface** — one codebase ships to the browser (Blazor/WASM), mobile (.NET MAUI) and desktop (Windows/macOS/Linux)
- 🎯 **Deterministic dual-tick core** — fixed 30 Hz simulation with fixed-point math, interpolated rendering as fast as the surface allows
- 🔌 **Batteries included** — WebGPU/WebGL2/native-wgpu rendering backends and a built-in multiplayer stack with client prediction
